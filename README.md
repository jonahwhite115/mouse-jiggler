# Mouse Jiggler for Windows

A mouse jiggler that nudges the cursor by a single pixel so Windows never thinks you left. No power settings touched, no admin rights, nothing installed.

## Download

[Download the latest release](../../releases/latest) — portable build, no installer and no account.

## What it does

- Keeps your PC awake without changing power settings
- Mouse jiggler mode: a 1 pixel nudge you never notice
- Invisible key mode (F13) that no application reacts to
- Interval from 30 seconds up to 60 minutes
- Presets: Office, MMO, Corp PC
- Activity log showing the last nudge
- Portable, no installer and no admin rights
- Free and open source, MIT licensed, no ads

## Requirements

Windows 10 or 11, 64-bit. No admin rights, nothing written to the registry.
